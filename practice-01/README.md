# Задание 2. Типы данных и преобразования

Перед запуском были сделаны предположения о результате выражений.

| Выражение | Ожидание до запуска | Фактическое значение | Тип результата | Объяснение |
|---|---|---|---|---|
| `"8" + 2` | `"82"` | `82` | `string` | Строка и число объединяются в строку |
| `"8" - 2` | `6` | `6` | `number` | При вычитании строка преобразуется в число |
| `Number("8") + 2` | `10` | `10` | `number` | Строка явно преобразуется в число |
| `"12" > "3"` | `false` | `false` | `boolean` | Строки сравниваются как строки |
| `12 === "12"` | `false` | `false` | `boolean` | Строгое сравнение учитывает тип |
| `Number("")` | `0` | `0` | `number` | Пустая строка при преобразовании становится `0` |
| `Number("text")` | `NaN` | `NaN` | `number` | Строку нельзя преобразовать в число |
| `Boolean("false")` | `true` | `true` | `boolean` | Любая непустая строка является `true` |
| `typeof null` | `object` | `object` | `string` | Это особенность JavaScript: `typeof null` возвращает `"object"` |
| `typeof NaN` | `number` | `number` | `string` | `NaN` имеет тип `number` |

Основные выводы:

- оператор `+` со строкой может выполнять конкатенацию;
- при арифметических операциях JavaScript может автоматически преобразовывать строки в числа;
- `NaN` означает некорректный числовой результат, но его тип всё равно `number`;
- непустая строка `"false"` при преобразовании в `Boolean` даёт `true`.

# Задание 5. Отладка программы

## Исходная версия

В исходной программе были две ошибки.

Первая ошибка находилась в строке:

    const completedTotal = completedText + additionalText;

Обе переменные имели строковый тип, поэтому вместо сложения чисел происходило объединение строк.

Вторая ошибка была в условии цикла:

    for (let taskNumber = 1; taskNumber < 4; taskNumber += 1)

При таком условии цикл выполнялся только для значений `1`, `2` и `3`.

Исходный результат программы:

    Выполнено: 32
    Осталось: -24
    Контрольная сумма: 6

## Исправление

Для исправления первой ошибки использовано явное преобразование строк в числа:

    const completedTotal = Number(completedText) + Number(additionalText);

Для исправления второй ошибки изменена граница цикла:

    for (let taskNumber = 1; taskNumber <= 4; taskNumber += 1)

После исправления результат:

    Выполнено: 5
    Осталось: 3
    Контрольная сумма: 10

## Таблица отладки

| Ошибка | Что наблюдалось | Причина | Исправление | Результат после исправления |
|---|---|---|---|---|
| Обработка количества задач | `Выполнено: 32` | Строки `"3"` и `"2"` объединялись оператором `+` | Использован `Number()` | `Выполнено: 5` |
| Граница цикла | `Контрольная сумма: 6` | Условие `< 4` не включало число 4 | Установлено `<= 4` | `Контрольная сумма: 10` |

Для проверки выполнения цикла использовалась точка останова на строке:

    controlSum += taskNumber;

При пошаговом выполнении значения `taskNumber` были:

    1 → 2 → 3 → 4

а значение `controlSum` изменялось:

    1 → 3 → 6 → 10
