| № | Прогноз до запуска | Фактический результат | Причина |

| 1 | sum(2, 3) даст число 5; sum("2", 3) даст не 5, а строку "23" | 5 и 23 (строка) | Оператор + при строке в одном из операндов склеивает строки, а не складывает числа. Функция сама ничего не преобразует. |
| 2 | square(4) вернёт не 16, а undefined | undefined | В теле с { } нет return, результат value * value вычисляется и пропадает. |
| 3 | product.stock станет 5, product === alias будет true | 5 и true | alias = product не создаёт копию, обе переменные указывают на один объект. const запрещает только переприсваивание переменной, а не изменение свойств. |
| 4 | products[0].stock станет 7; products === copy будет false; products[0] === copy[0] будет true | 7, false, true | Spread создал новый массив, но объекты внутри остались те же (поверхностная копия). Изменение через copy[0] видно и в products[0]. |
| 5 | product.stock останется 3, first.stock будет 8, second.stock будет 3; product === first будет false | 3 8 3 и false | Spread создаёт новый объект. При повторе имени побеждает последнее значение: в first stock: 8 стоит после spread, в second после него идёт ...product и возвращает 3. |
| 6 | makeCaption() и (undefined) дадут «Без названия»; (null) даст null; ("") даст пустую строку | «Без названия», «Без названия», null, пустая строка | Значение по умолчанию срабатывает только при отсутствии аргумента или undefined. null и "" это обычные значения. |
